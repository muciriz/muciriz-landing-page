# Muciriz Landing Page

Official web showcase and customer landing page for **Muciriz Traders** — celebrating Kerala's coastal maritime heritage with modern hygienic seafood processing, stone-ground heirloom spices, and farm-fresh vegetable bunches.

---

## 🌊 Core Highlights

- **Dual Brand Architecture**:
  - **Muciriz ShoreCatch**: 100% chemical-free, fresh marine and backwater catch (Karimeen, Neymeen, Tiger Prawns, Pomfret, Sardines), descaled, cut, and vacuum-sealed in odor-free food trays.
  - **Muciriz Kitchen & Farm Bunches (Zuriyani Kitchen & VegEze)**: Authentic stone-ground fish curry masalas, fish fry marinades, and fresh farm vegetable bunches.
- **Chilled Daily Provisions**: 4-column catalog showcasing cuts with gross vs. true net weights and transparent pricing.
- **Android Mobile App Integration**: Exclusive mobile ordering, continuous cold-chain fleet tracking, and morning delivery scheduling.
- **Full Legal Compliance**: Integrated policies viewer featuring Customer Privacy Policy, Customer Terms & Conditions, Staff Privacy Policy, and Staff Terms & Conditions with official grievance contact details.

---

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler / Dev Server**: [Vite](https://vitejs.dev/)
- **Styling**: Custom Vanilla CSS design system with editorial typography (*Playfair Display* & *Plus Jakarta Sans*) and responsive grid layouts.
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or newer recommended)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/muciriz/muciriz-landing-page.git

# Navigate into the project folder
cd muciriz-landing-page

# Install dependencies
npm install
```

### Running Locally
```bash
npm run dev
```
The application will start on `http://localhost:5174/`.

### Production Build
```bash
npm run build
```
Generates production-ready static assets in the `dist/` directory.
